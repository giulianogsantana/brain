# Encerramento do desktop
- Jun/2026: ~45 municípios ainda só com desktop; desligamento definido para **31/08/2026**.
- Diretrizes discutidas: migração de contratos vigentes até **31/12/2026**; acesso aos dados por 20 anos; restrições ao uso do desktop para migração.
- Após o desligamento, revendas pediram religamento (ex.: [[solucao-mg]], que usa o desktop para migrar bases de concorrentes).
- **CEO autorizou 30 dias** de liberação para migrações em andamento; lista de revendas e entidades enviada; termo jurídico solicitado ("Termo de Ciência para Revendas - Descontinuidade Desktop").
- Caso RJ: [[custom]]/[[sigen]], decisão judicial de Japeri (14/07/2025).
- Princípio: a responsabilidade de preparar motores de migração não pode voltar para a Betha depois da descontinuidade anunciada.
