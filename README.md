# Brain do Giuliano

Segundo cérebro em Markdown, inspirado no [gbrain](https://github.com/garrytan/gbrain) de Garry Tan. Funciona hoje como uma pasta comum (Obsidian, GitHub, Claude, ChatGPT) e está pronto para ser importado no gbrain depois (`gbrain import ./`), sem retrabalho.

## Como navegar

| Pasta | O que tem |
|---|---|
| `BRAIN.md` | Regras do brain: leia antes de escrever qualquer coisa |
| `perfil/` | Quem é o Giuliano, como trabalha, preferências de resposta, ferramentas |
| `pessoas/` | Uma página por pessoa (colegas, parceiros, contatos) |
| `organizacoes/` | Betha, revendas, parceiros, órgãos públicos, concorrentes |
| `areas/` | Frentes de trabalho ativas ou recentes, com status e pendências |
| `conhecimento/` | Frameworks, modelos de parceria, princípios, aprendizados |
| `decisoes/` | Log de decisões com data, quem decidiu e por quê |
| `reunioes/` | Resumos de reuniões (tl;dv, Plaud, anotações) |
| `rotinas/` | Rituais de captura e revisão, automações, prompts |
| `inbox/` | Captura rápida, triada na revisão semanal |
| `fontes/` | Material bruto (transcrições do ChatGPT etc.). Fonte, não verdade curada |
| `templates/` | Modelos de página |
| `privado/` | Vida pessoal e conversas sensíveis. **Fora do git** (ver `.gitignore`) |
